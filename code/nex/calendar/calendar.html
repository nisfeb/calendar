Set up your own OAuth client (once)
  1. In the Google Cloud console make a project, open APIs & Services → OAuth consent screen, choose External, fill the name and your email, and add yourself as a test user. It can stay in Testing.
  2. Enable the Google Calendar API under Library.
  3. Under Credentials make an OAuth client of type Web application. Authorized redirect URI, exactly:
