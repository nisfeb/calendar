Google Calendar
Set up your own OAuth client (once)
  1. In the Google Cloud console make a project, open APIs & Services → OAuth consent screen, choose External, fill the name and your email, then press Publish app so it is In production. Left in Testing, Google ends the sign-in after 7 days. At Connect, Google warns the app is unverified; it is yours, so go on (Advanced → go to the app). A project inside a company's Google Workspace can choose Internal instead.
  2. Enable the Google Calendar API under Library.
  3. Under Credentials make an OAuth client of type Web application. Authorized redirect URI, exactly:
  4. Paste the client id and secret here, save, then press Connect.
